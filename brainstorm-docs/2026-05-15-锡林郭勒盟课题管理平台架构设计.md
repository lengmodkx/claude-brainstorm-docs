# 锡林郭勒盟教育系统课题管理平台 - 架构设计文档

## 一、项目概述

### 1.1 项目背景
针对当前教育系统课题申报、中期检查、结题验收过程中存在的纸质化流程繁琐、数据孤岛、经费监管困难、评审透明度不足等问题。

### 1.2 项目目标
构建一个集"申报-评审-立项-中期-结题-成果转化"于一体的全流程数字化平台，实现课题数据的动态可视化和无纸化办公。

### 1.3 系统规模
- 接入单位：500+ 所学校/单位
- 并发用户：1000 人
- 部署方式：全量上线
- 技术栈：Java + Spring Cloud + yudao-cloud + Flowable

## 二、技术架构

### 2.1 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 后端框架 | Spring Cloud + Spring Boot 3.x | 微服务架构，基于 yudao-cloud |
| 前端框架 | Vue 3 + Element Plus (PC) / Vant (H5) | 管理后台 + 移动端 |
| 数据库 | MySQL 8.0 主从集群 | 主库 + 读写分离 |
| 缓存 | Redis Cluster | 热点数据缓存 |
| 工作流 | Flowable 6.x | 流程引擎 |
| 文件存储 | MinIO / 阿里云 OSS | 私有化或云端 |
| 消息队列 | RabbitMQ | 异步通知 |
| 注册/配置 | Nacos / Sentinel | 服务治理 |

```
┌─────────────────────────────────────────────────────────────┐
│                      客户端层                               │
│   Vue3 管理后台    │    Vant H5 移动端    │   第三方 API   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│              yudao-gateway（API网关）                        │
│         统一入口 / 路由转发 / 认证鉴权 / 限流熔断            │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                   yudao-cloud 基础服务层                     │
│  yudao-system │ yudao-workflow │ yudao-file │ yudao-sms    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                   业务微服务层（自研模块）                    │
│  project-service │ review-service │ fund-service │ result-service
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                      基础设施层                              │
│    MySQL    │    Redis    │   MinIO    │   RabbitMQ       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                      外部系统对接                            │
```

## 三、微服务模块设计

### 3.1 模块概述

| 服务名 | 模块 Key | 职责 |
|--------|----------|------|
| project-service | 申报管理 | 课题申报、查重检测、开题报告、变更申请 |
| review-service | 评审管理 | 专家库、盲评分配、在线打分、立项判定 |
| fund-service | 经费管理 | 经费预算、下拨管理、合同签署、电子签章 |
| result-service | 成果管理 | 成果库、查重检测、证书生成、归档推送 |
| auth-adapter | 认证适配 | 认证源配置管理、统一认证适配层 |

### 3.2 复用 yudao-cloud 能力

基于 yudao-cloud 微服务模块模式开发，复用以下能力：
- 用户/角色/菜单/权限管理
- 机构管理（三级联动）
- 代码生成器（Vue + Java）
- Flowable 工作流集成
- 文件管理服务
- 短信/邮件服务
- 操作日志审计

## 四、核心功能模块设计

### 4.1 申报管理模块（project-service）

**核心功能：**
- 课题在线填报（富文本、公式、图表附件）
- 申报书模板管理（自定义模板、版本控制）
- 申报时间窗口（自动开放/关闭）
- 查重检测（申报时与已立项课题、成果库比对）
- 草稿自动保存（断网自动恢复）

**Flowable 流程：**
```
提交申报 → 查重检测 → 格式校验 → 受理成功/退回修改
```

**关键表设计：**
- `project_declaration` - 申报课题主表
- `project_attachment` - 申报附件表
- `declaration_template` - 申报模板表
- `project_duplicate_check` - 查重记录表

### 4.2 评审管理模块（review-service）

**核心功能：**
- 专家库管理（学科分类、职称、单位、回避设置）
- 智能匹配推荐（根据课题关键词匹配）
- 盲评加密（自动隐藏申报人/单位信息）
- 评审分配（1+N 策略，自动规避本单位专家）
- 在线评审（打分、评语、汇总得分）
- 立项判定（系统自动判定）

**Flowable 流程：**
```
专家抽取 → 任务分配 → 盲评打分 → 评语填写 → 得分汇总 → 立项判定
```

**关键表设计：**
- `expert_info` - 专家信息表
- `expert_exclude_unit` - 专家回避单位表
- `review_task` - 评审任务表
- `review_score` - 评审打分表
- `anonymous_mapping` - 匿名映射表

### 4.3 经费与合同管理模块（fund-service）

**核心功能：**
- 经费预算（设备费、劳务费、差旅费等分类）
- 预算校验（劳务费上限自动校验）
- 经费下拨（按审批节点分批次拨款）
- 合同管理（电子任务合同书、电子签章）

**与 Flowable 结合：**
```
立项通过 → 生成经费预算 → 预算审批 → 拨款确认 → 合同生成 → 电子签章
```

**关键表设计：**
- `fund_budget` - 经费预算表
- `fund_allocation` - 经费下拨记录表
- `contract_info` - 合同信息表
- `contract_sign_record` - 签章记录表

### 4.4 成果管理与数据中心模块（result-service）

**核心功能：**
- 成果库（自动归集论文、专利、专著）
- 成果超市（可检索、浏览）
- 查重检测（申报时 + 结题时双重检测）
- 结题证书生成（含二维码防伪）
- 数据统计（按学科、单位、年度）

**Flowable 流程：**
```
结题材料提交 → 成果审核 → 查重检测 → 证书生成 → 归档推送
```

**关键表设计：**
- `result_info` - 成果信息表
- `result_attachment` - 成果附件表
- `similarity_check` - 相似度检测记录表
- `certificate_info` - 证书信息表

### 4.5 系统管理与权限模块

**多角色权限：**
- 管理员（教育厅/局）
- 依托单位管理员（学校科研处）
- 普通申报人（教师/学生）
- 评审专家

**三级联动：**
- 省-市-校三级机构管理
- 下级数据独立，上级可汇总查看
- 数据权限灵活配置

**操作日志：**
- 完整记录谁、什么时间、查看了什么课题、下载了什么文件

## 五、Flowable 流程设计

### 5.1 课题全生命周期流程

```
申报 ──→ 评审 ──→ 立项 ──→ 开题 ──→ 中期 ──→ 结题 ──→ 成果归档
  │        │        │        │        │        │
  ↓        ↓        ↓        ↓        ↓        ↓
查重     盲评     合同     报告     检查     验收
检测     分配     签署     提交     预警     证书
```

### 5.2 各阶段 Flowable 流程

| 阶段 | 流程 Key | 主要节点 |
|------|----------|----------|
| 申报 | `declaration_flow` | 提交→查重→受理/退回 |
| 评审 | `review_flow` | 抽取→分配→盲评→打分→汇总→判定 |
| 立项 | `project_flow` | 立项审批→预算审批→合同签署→拨款 |
| 开题 | `opening_flow` | 开题报告提交→审核 |
| 中期 | `midterm_flow` | 中期检查→预警提醒→检查审核 |
| 结题 | `closing_flow` | 结题材料→成果审核→查重→证书→归档 |

## 六、非功能需求设计

### 6.1 安全性（等保三级）
- 数据加密：AES-256 存储敏感数据
- 传输安全：HTTPS 全链路加密
- 日志审计：所有操作完整记录
- 身份认证：支持 OAuth2 + LDAP 双模式
- 盲评机制：双向匿名

### 6.2 性能设计（1000 并发）
- 申报截止前：临时扩容 + 限流策略
- 文件上传：分片上传 + 秒传校验
- 数据库：读写分离 + 分库分表（按机构ID）
- Redis 缓存热点数据

### 6.3 移动端 H5
- Vant 组件库开发
- 专家评审（手机端打分、写评语）
- 申报人查看立项状态、接收通知

### 6.4 兼容性
- 浏览器：Chrome / Edge / 360 极速模式
- 操作系统：统信 UOS、麒麟等国产系统

## 七、数据对接设计

### 7.1 统一身份认证对接
- 认证源配置管理页面（管理员可配置多个认证系统）
- 双模式自动识别（省级平台 + 校级平台）
- 用户自动同步（首次登录创建本地账号）

### 7.2 财务系统对接
- 提供财务中间件服务
- 统一对接省财政一体化系统
- 拨款申请 → 财务审核 → 拨款确认 → 回写状态

### 7.3 档案系统对接
- 结题完成后自动推送至电子档案系统
- 推送内容：课题信息 + 成果附件 + 评审意见

### 7.4 数据上报
- 支持导出 XML / Excel 格式
- 符合教育部/上级部门报表模板

## 八、历史数据迁移

### 8.1 迁移范围
- 3-5 年历史课题数据
- 旧系统 Excel 或数据库导出

### 8.2 迁移流程
```
旧系统导出 → 数据清洗 → 格式转换 → 数据校验 → 导入新系统
                                              ↓
                                      迁移报告生成
```

### 8.3 迁移步骤
1. 数据采集：从旧系统导出 Excel/CSV
2. 数据清洗：去重、规范格式、补充缺失字段
3. 格式映射：旧字段 → 新表结构
4. 数据校验：必填项、关联关系
5. 试导入：测试环境验证
6. 生产执行：确认后全量导入
7. 迁移报告：记录成功/失败条数
