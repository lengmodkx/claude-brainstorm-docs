## 视觉风格

### 主题
- 自动跟随Windows系统主题
- 提供手动切换按钮
- 深色模式：深蓝灰背景 + 玻璃态卡片
- 浅色模式：浅灰背景 + 白色卡片

### 色彩方案（深色模式）
- 背景：`bg-slate-900`
- 卡片背景：`bg-slate-800/50` + `backdrop-blur-lg`
- 卡片边框：`border-slate-700/50`
- 主文字：`text-slate-100`
- 次要文字：`text-slate-400`
- 活跃指示：`text-emerald-400` / `bg-emerald-500`
- 非活跃指示：`text-slate-500` / `bg-slate-500`

### 组件规范
- 卡片圆角：`rounded-2xl`
- 卡片阴影：`shadow-xl`
- 内边距：`p-6`
- 间距：`gap-6`

## 功能模块

### 1. 视频预览区域
- 尺寸：16:9比例，占左侧45%宽度
- 自动检测摄像头：有摄像头显示摄像头，无摄像头显示屏幕截图
- 底部状态栏：显示当前模式
- 右上角切换按钮：可手动切换

### 2. 设备信息卡片
- 设备名称：从配置读取
- 开机时间：计算系统启动时长
- 设备状态：在线/离线
- 设置按钮：打开设置面板

### 3. 软件使用列表
- 折叠式设计：默认显示5个
- 每个软件项：图标/指示点、名称、窗口标题、使用时长
- 活跃软件：绿色指示点
- 非活跃软件：灰色指示点
- 展开按钮：查看更多

## 交互设计

### 主题切换
- 点击主题按钮切换
- 保存用户偏好到localStorage
- 下次启动自动应用

### 软件列表展开
- 点击"展开查看更多"显示全部
- 点击"收起"回到精简模式
- 使用动画过渡

### 视频区域
- 自动轮询检测摄像头状态
- 摄像头不可用时自动降级到屏幕截图
- 可手动切换预览模式
