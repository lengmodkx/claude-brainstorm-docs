# 共享算力平台 — 管理平台功能设计

> 设计日期: 2026-05-16
> 项目: Share Compoter
> 状态: 设计完成

## 背景

Share Compoter MVP 已完成，包含 server（Go + Gin + PostgreSQL + Redis）、agent、web 控制台、cli 工具，跑通了 Provider 注册设备 → Renter 租用计算资源的闭环。

现在需要再做一个**独立管理平台**，管理注册设备和使用情况。

## 技术选型

- **前端**: Vue 3 + Element Plus / Naive UI，独立项目
- **后端**: Java Spring Boot，独立项目
- **数据库**: 共用现有 share-compoter 的 PostgreSQL 实例和数据库
- **认证**: 两种角色 — 管理员 (admin) 和 Provider（设备出租方），管理员全局视角，Provider 只管理自己的设备

## 角色与权限

| 角色 | 可见范围 | 核心操作 |
|------|----------|----------|
| 管理员 | 全部数据 | 用户管理、设备管理、任务管理、营收统计、系统配置 |
| Provider | 自己的数据 | 我的设备、设备监控、我的任务、我的收益 |

---

## 模块划分

### 1. 仪表盘 (Dashboard)

**管理员视角：**
- 数据概览卡片：总用户数、总设备数、在线设备数、运行中任务数、今日营收
- 设备状态分布：饼图（在线 / 离线 / 忙碌）
- 24h 任务趋势：折线图（提交量、完成量、失败量）
- 今日营收趋势：柱状图

**Provider 视角：**
- 我的设备概览：设备数、在线率
- 今日收益概览
- 近期任务趋势

### 2. 用户管理（管理员专属）

- 用户列表（分页、搜索：手机号 / 邮箱 / 角色筛选）
- 用户详情：基本信息、名下设备数、历史任务数、累计消费
- 操作：启用 / 禁用用户、修改余额

### 3. 设备管理

**管理员 — 全局设备列表**
- 列表字段：设备名、所属用户、GPU 型号、CPU/内存、OS、状态标签、定价、最后心跳时间
- 搜索筛选：设备名、GPU 型号、状态
- 设备详情：基本信息、实时心跳数据（CPU/内存/GPU 使用率）、所属用户信息
- 操作：强制下线、修改状态、查看该设备的任务历史

**Provider — 我的设备**
- 列表字段：设备名、GPU/CPU/内存配置、状态标签、定价、最后心跳时间
- 实时监控：选中设备后展示最近心跳数据（CPU 使用率、内存使用率、GPU 使用率），简单折线图
- 操作：修改定价、注销设备（软删除）、注册新设备

### 4. 任务管理

**管理员 — 全局任务列表**
- 列表字段：任务类型、租户、目标设备、状态标签、创建时间、耗时
- 搜索筛选：任务类型、状态、时间段
- 任务详情：命令内容、执行设备、开始/结束时间、资源用量 (JSONB)、输出日志
- 操作：取消排队中的任务

**Provider — 我的设备上的任务**
- 列表字段：任务类型、租户、状态、耗时、费用
- 任务详情：命令内容、开始/结束时间、输出日志、资源用量

### 5. 计费与收益

**管理员 — 消费记录与营收**
- 消费记录列表（分页，按用户/设备/时间筛选）
- 营收统计：按天/周/月汇总，按设备类型汇总
- 报表导出 (CSV)

**Provider — 我的收益**
- 收益概览：今日收益、本月收益、累计收益
- 收益明细列表：按任务列出，含时长、是否使用 GPU、费用
- 收益趋势：按天汇总的柱状图

### 6. 系统设置（管理员专属）

- 基础定价配置（默认 ¥/小时，GPU 溢价系数）
- 心跳超时时间配置

### 7. 操作日志（管理员专属）

- 管理员操作审计记录：操作人、操作类型、操作对象、详情、时间

## 数据库变更

复用现有 `share_compoter` 数据库，变更如下：

**现有表新增字段：**

| 表 | 新增字段 | 类型 | 说明 |
|----|----------|------|------|
| users | disabled | BOOLEAN DEFAULT false | 用户启用/禁用标记 |
| devices | deleted_at | TIMESTAMP | 软删除时间 |

**新增表：**

`system_config` — 系统配置

| 字段 | 类型 | 说明 |
|------|------|------|
| key | VARCHAR(100) PK | 配置键（如 `base_price_per_hour`, `gpu_premium_ratio`） |
| value | TEXT | 配置值 |
| updated_at | TIMESTAMP | 更新时间 |

`audit_logs` — 管理员操作审计

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | |
| admin_id | UUID FK → users | 操作人 |
| action | VARCHAR(50) | 操作类型（enable_user / disable_user / force_offline / etc） |
| target_type | VARCHAR(50) | 操作对象类型（user / device / task） |
| target_id | UUID | 操作对象 ID |
| detail | JSONB | 操作详情 |
| created_at | TIMESTAMP | 操作时间 |
