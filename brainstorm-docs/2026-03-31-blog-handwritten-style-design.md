# 博客视觉风格重设计文档

**日期**: 2026-03-31
**风格名称**: 手写笔记 (Handwritten Notes)
**目标**: 减少"AI味"，增加人文温度

---

## 1. 设计理念

像是一本打开的纸质笔记本，有手写的痕迹、铅笔的质感、不完美的线条。传达"这是一个真实的人写的"的感觉。

### 核心特征
- **不完美**: 故意的不对称、偏移、手绘感
- **纸质质感**: 暖色调背景，像真实纸张
- **手写元素**: 标题用手写体，模拟马克笔/钢笔
- **克制**: 减少动画、阴影、圆角

## 2. 设计系统

### 2.1 配色方案

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-paper` | `#FDFBF7` | 主背景（暖白色，像旧纸张） |
| `--color-paper-dark` | `#F5F1E8` | 次级背景 |
| `--color-ink` | `#2C3E33` | 主文字/墨绿色 |
| `--color-ink-light` | `#4A6355` | 次要文字 |
| `--color-accent` | `#C75B39` | 强调色（砖红） |
| `--color-accent-muted` | `#D97B5D` | 柔和强调 |
| `--color-pencil` | `#3D3D3D` | 正文文字（深灰，像铅笔） |
| `--color-border` | `#D4CFC4` | 边框/分隔线 |

### 2.2 字体方案

| 用途 | 字体 | 备选 |
|------|------|------|
| 手写标题 | `Patrick Hand` | `Caveat` |
| 正文 | `Inter` | `Source Serif 4` |
| 代码 | `JetBrains Mono` | `Fira Code` |

### 2.3 圆角策略

避免完美对称的大圆角，使用小且不规则的圆角：

```css
/* 小圆角 - 像纸张 */
--radius-sm: 2px;

/* 不规则圆角 - 手绘感 */
--radius-hand: 2px 4px 3px 5px;
```

## 4. "AI味" 消除对照表

| AI味特征 | 当前实现 | 改造方案 |
|---------|---------|---------|
| 紫色调主色 | `#8B5CF6` | 改为墨绿 `#2C3E33` |
| 完美大圆角 | `rounded-2xl` | 小圆角或直角 |
| 过多阴影 | `shadow-lg` 多处 | 减少/移除阴影 |
| 悬浮动画 | `hover:scale-105` | 移除或减少 |
| 毛玻璃效果 | `backdrop-blur` | 移除 |
| 渐变色 | `bg-gradient-to-r` | 使用纯色 |
| 科技感图标 | SVG 图标 | 简化或使用文字 |
